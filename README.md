# Xclipse Gaming

Unofficial Winlator 11.2 source-based edition for Samsung Exynos / Xclipse.

Default: Vortek using the Android system Vulkan driver, VirGL OpenGL fallback, DXVK, 960x544, Box64 Intermediate, FPS HUD. Gladio and WineD3D remain available. No root. No performance guarantee; test on device. Turnip is not offered in the Vulkan picker in this edition.

Upstream source: https://github.com/brunodev85/winlator-app/tree/a030f552f452158a2db64fdb32b490fa19c0b48d . Upstream license and credits retained. This is not a Samsung or official Winlator release. The upstream Android package name is retained because the runtime uses hardcoded paths. A different APK signature may require removing an existing Winlator installation after backing up containers.

# Winlator

Winlator is an Android application that lets you to run Windows (x86_64) applications with Wine and Box86/Box64.<br>
This repository stores the latest updates for the Winlator app source.<br>
For more information and releases, please visit the main repository: https://github.com/brunodev85/winlator
